# The fonts in this folder

Copied unchanged from the web app (`lexpad_front`, `apps/web/src/assets/fonts/`), so the panel
uses the web app's own faces. Every face here is under the **SIL Open Font License 1.1**, which
permits bundling them, and requires the licence to travel with the files; that is what this file
is. The full text is at <https://openfontlicense.org/>. The reserved font names are the family
names below; none of these files is renamed or modified (the subsets are the ones Google Fonts
publishes).

| Family            | Covers                                 | Source                                                |
| ----------------- | -------------------------------------- | ----------------------------------------------------- |
| Schibsted Grotesk | the interface, and Latin everywhere    | <https://fonts.google.com/specimen/Schibsted+Grotesk> |
| Vazirmatn         | Persian, Arabic, Urdu, Pashto, Kurdish | <https://fonts.google.com/specimen/Vazirmatn>         |
